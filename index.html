AI·지도 API 설정

아래 두 개의 키를 Supabase Edge Function Secrets에 등록해 주세요. 키는 공개 GitHub 코드에 입력하지 않습니다.

  1. GEMINI_API_KEY — Google AI Studio에서 발급한 Gemini 키
  2. GOOGLE_MAPS_API_KEY — Places API (New)와 Routes API를 활성화한 Google Maps 키
Supabase API 비밀키 설정 열기 ↗

이 키는 Supabase 서버에서 사용합니다. API 제한에서 Places API (New)와 Routes API만 허용하고, 서버 호출과 맞지 않는 웹사이트 리퍼러 제한은 적용하지 마세요. 사용량 한도도 설정하세요.
