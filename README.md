# WAYPOINT — 여행 계획과 기록을 한곳에서

WAYPOINT는 여행지 탐색부터 일정·지도·예산·준비물까지 한곳에서 정리하는 여행 플래너입니다.

## 주요 기능
- 이메일 아이디 + 비밀번호 회원가입 및 로그인
- 이메일 확인을 통한 계정 활성화
- 이메일 비밀번호 재설정 및 새 비밀번호 등록
- AI 기반 날짜별 일정 초안 생성
- Google Places 실제 장소 후보 확인
- Google Routes 이동 경로 계산
- 여행별 클라우드 저장 및 기기 간 동기화
- 여행 예산, 체크리스트, 일정 내보내기
- 모바일 대응 및 PWA 기본 지원

## 인증 흐름
Supabase Auth의 이메일/비밀번호 인증을 사용합니다. 가입 확인과 비밀번호 재설정에만 이메일 링크가 사용되며, 일반 로그인은 이메일 아이디와 비밀번호로 진행합니다. 비밀번호는 브라우저에 저장하지 않습니다.

## 서버 설정
Supabase Edge Function Secrets에 `GEMINI_API_KEY`, `GOOGLE_MAPS_API_KEY`를 등록합니다. 비밀 API 키를 브라우저 코드나 GitHub 저장소에 입력하지 않습니다.
