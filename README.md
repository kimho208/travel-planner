# Voyage — AI 올인원 여행 플래너

HTML, CSS, Vanilla JavaScript로 만든 반응형 여행 계획 관리 웹앱입니다.

## 현재 구현된 기능
- PC/모바일 반응형 레이아웃
- 단계별 여행 생성 마법사
- 여행별 저장 및 상태 관리 (LocalStorage)
- 기본 일정 초안 생성 및 직접 일정 추가/삭제
- 항목별 예산 입력과 자동 합계 계산
- 예시 기반 교통패스/개별 결제 비교
- 여행 체크리스트
- JSON 백업 및 복원
- 일정 ICS 내보내기
- 인쇄/PDF 저장
- 라이트/다크 테마
- PWA manifest 및 Service Worker

## 아직 연동되지 않은 기능
- 실제 LLM 기반 AI 일정 생성
- 지도 및 실시간 경로·이동 시간
- 실시간 항공권/호텔/식당 정보와 예약 가능 여부
- 실시간 교통 요금 및 패스 데이터
- 환율 API
- 계정·클라우드 동기화 및 실시간 동행자 공유

실제 데이터 API가 연결되기 전까지 예시 데이터와 계산은 실제 정보로 간주하지 마세요. 브라우저 코드에 비밀 API 키를 넣지 말고, 추후 서버리스 프록시를 사용하세요.

## 로컬 실행
브라우저에서 `index.html`을 직접 열면 기본 UI는 실행되지만, PWA 및 Service Worker는 보안상 HTTPS 또는 localhost 환경이 필요합니다.

Python이 설치된 경우 프로젝트 폴더에서:

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 생성합니다.
2. 이 프로젝트의 파일과 폴더를 저장소 루트에 업로드합니다.
3. 저장소 Settings → Pages로 이동합니다.
4. Deploy from a branch를 선택합니다.
5. `main` 브랜치와 `/(root)` 폴더를 선택하고 저장합니다.
6. 표시되는 GitHub Pages 주소로 접속합니다.

프로젝트 하위 경로 배포를 고려해 로컬 리소스는 상대경로를 사용합니다.

## 데이터 저장 안내
여행 데이터는 현재 브라우저의 LocalStorage에 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으며 기기 간 자동 동기화는 제공하지 않습니다. Settings에서 JSON 백업을 정기적으로 다운로드하세요.
